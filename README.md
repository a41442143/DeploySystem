## 2. 使用情境與操作範例


### 情境 A：靜態網站

預期輸入: 使用者在指定資料夾中存放html檔案
操作:
    完整部署:
        系統會自動執行檢查與部署兩動作
    檢查:
        系統會有使專案可以運行的最低標準檢查
        系統可以讓使用者自行調整要新增哪些檢查
輸出: 網站成功部署後會顯示運行的狀態，連線IP，否則會顯示錯誤訊息

### 情境 B：Flask 網站

預期輸入: 使用者給一個 Flask 專案存放在指定位置，或者操作系統選擇該專案
操作:
    完整部署:
        系統會自動執行檢查與部署兩動作
    檢查:
        系統會有使專案可以運行的最低標準檢查
        系統可以讓使用者自行調整要新增哪些檢查
輸出: 網站成功部署後會顯示運行的狀態，連線IP，否則會顯示錯誤訊息

### 失敗案例情境:
    1.http回應測試未通過

    2.python語法未通過，導致無法啟動網站或者程式無法正確運行

    3.port衝突無法使用(已被占用)

    4.容器啟動錯誤

    5.設定檔錯誤

#定義通過檢查不但container 要 running 且 http 要回傳200，否則網站不算成功運行
